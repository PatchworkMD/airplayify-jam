# Changelog

## 0.1.0-alpha.1

First public experimental binary release.

- Native menu-bar output groups and Spotify audio capture.
- Optional global volume keys in direct builds; in-app sliders for Store policy builds.
- Optional BlackHole installation defaults to No.
- Build deployment target matches the app minimum macOS version.
- Reject ambiguous receiver names and bound sender audio buffering.
- Remove predictable shared temporary files from credential scanning.

Real-device audio, synchronization, volume, stop/restore and repeated permission checks remain pending. This alpha is not notarized or submitted to the Mac App Store.
